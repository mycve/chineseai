# 自博弈规则与价值标签

## 规则边界

UCI 与竞技评测保持默认比赛规则，包括重复裁决、长将长捉限制和自然限着。自博弈启动局面显式启用训练规则；该设置随 Position 克隆进入搜索，不改变 UCI 默认值。

训练允许第二次普通重复，第三次同局面（含行棋方）出现时由自博弈调度器截断，不判和。训练禁用自然限着和棋，仅保留双方没有车、马、炮、兵卒的明确子力不足和棋。炮残局快速判和不用于训练。长将、长捉违规着仍由规则过滤。

## 终局与截断

每轮先裁决当前局面，再检查训练预算，保证最后一步形成的将死或困毙优先结束。原始合法着为空时区分将死与困毙；经历史规则过滤后无着单独统计。正常流程不检查将帅缺失，合法走法不能吃将帅。

真实终局按胜负和生成 TD(λ) 目标。循环或步数截断保留策略目标，但整局 value_weight=0，不参与价值损失、价值误差、相关性及分阶段指标。策略和价值损失分别按有效权重归一化；无有效价值样本时不写入虚假的零误差曲线。

截断不是模型应预测的和棋，也不向网络添加剩余训练预算通道。策略训练仍会更新共享网络，不等于冻结价值输出。

## TensorBoard

沿用原有 TensorBoard 运行目录，不添加版本后缀。旧事件文件保留；已删除标签不再写入，但其历史曲线仍可能显示。

- `terminal/checkmate`、`terminal/stalemate`、`terminal/rule_blocked`：区分无着原因。
- `terminal/draw_insufficient_material`：训练中的明确和棋。
- `terminal/rule_win_red`、`terminal/rule_win_black`：历史规则裁决胜方。
- `truncation/repetition`、`truncation/max_plies`、`truncation/rate`：未知结果的截断。
- `selfplay/completed_games`：有真实结果的局数。
- `selfplay/draw_rate_completed`：真实和棋数 / 完成局数；没有完成局时不写入。
- `train/value_samples`：有效价值监督样本数。

删除将帅缺失、自然限着和棋、重复和棋、双方长将/长捉和棋及重复的总规则和棋标签。仍有实际意义的计数保留零值，以反映事件发生后下降到零。

## 旧数据

回放格式升为 v38，训练快照改为 `<配置路径>.replay.v38.lz4`。旧回放留在原路径，不自动载入或覆盖；模型格式不变，可以继续使用原有模型权重。旧 TensorBoard 事件文件保留，新标签在重新编译并启动训练后生效。
