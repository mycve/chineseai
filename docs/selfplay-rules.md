# 自博弈规则与价值标签

## 规则边界

自博弈、搜索、UCI 和竞技评测使用同一套规则实现，包括重复裁决、长将长捉限制、自然限着和子力不足。自博弈与竞技评测共用自然限着配置；UCI 使用其配置的限着阈值。

恢复普通二次重复、自然限着及规则实现中的子力不足和棋监督，不再设置训练专用规则或第三次重复截断。长将、长捉违规着仍由规则过滤。默认自博弈计算上限保持 200 ply，不把超时未决局面直接判和或判负。

## 终局与截断

每轮先裁决当前局面，再检查训练预算，保证最后一步形成的将死或困毙优先结束。原始合法着为空时区分将死与困毙；经历史规则过滤后无着单独统计。正常流程不检查将帅缺失，合法走法不能吃将帅。

真实终局按胜负和生成 TD(λ) 目标。只有预算截断保留策略目标但整局 value_weight=0，不参与价值损失、价值误差、相关性及分阶段指标。策略和价值损失分别按有效权重归一化；无有效价值样本时不写入虚假的零误差曲线。屏蔽截断标签防止伪和棋监督，但仍可能带来长局样本选择偏差，需监测截断率。

截断不是模型应预测的和棋，也不向网络添加剩余训练预算通道。策略训练仍会更新共享网络，不等于冻结价值输出。

## TensorBoard

沿用原有 TensorBoard 运行目录，不添加版本后缀。旧事件文件保留；已删除标签不再写入，但其历史曲线仍可能显示。

- `terminal/checkmate`、`terminal/stalemate`、`terminal/rule_blocked`：区分无着原因。
- `terminal/draw_repetition`、`terminal/draw_natural_limit`、`terminal/draw_insufficient_material`：合法和棋。重复和棋包含重复历史裁决中的双方长将/长捉和棋，不单设长期空计数。
- `terminal/rule_win_red`、`terminal/rule_win_black`：历史规则裁决胜方。
- `truncation/max_plies`、`truncation/rate`：预算截断局数和比例。
- `selfplay/completed_games`：有真实结果的局数。
- `selfplay/draw_rate_completed`：真实和棋数 / 完成局数；没有完成局时不写入。
- `train/value_samples`：有效价值监督样本数。

不再写入 `truncation/repetition`，不恢复将帅缺失或重复的总规则和棋标签。仍有实际意义的计数保留零值，以反映事件发生后下降到零。

## 旧数据

回放内容版本升为 v40，但继续使用已部署的 `<配置路径>.replay.v38.lz4` 路径，不更换目录或清空经验池。加载 v38 时保留样本、策略权重和元数据，将旧规则的价值权重一次性置零；加载 v39 保留有效价值权重。两种旧数据均标记新增历史信息未知，不能凭旧样本重建的重复走法不作伪造。下次保存写入 v40，不接受更早的未知格式。

模型格式升为 v22，可直接加载 v21 权重；新增输入及策略分支权重补零，保留原始网络输出，不要求从零训练。v38 回放迁移初期有效价值样本比例会暂时下降，随新数据进入恢复。是否改善和棋识别与棋力，需要固定对手和局面的对照评测确认。

恢复已有模型时跳过 `train_warmup_samples` 预热门槛，即使新版经验池为空，也按正常 `selfplay_samples_per_update` 收集新样本后继续训练。训练器仍要求经验池至少有一个 batch 的样本。随机初始化的新模型才需要补足预热样本。

## 网络历史输入

保留原有自然限着、重复次数和周期内将捉信息，新增“是否存在立即重复和棋走法”“这些走法占候选合法着的比例”“历史信息是否已知”三个标量。逐着标记由实际历史和现有裁决器计算，只对走后匹配历史局面的候选着执行精确裁决。

策略头新增一个依赖局面隐藏向量的可学习分数，仅加到重复和棋走法上；模型可根据优势或劣势学习避和或保和，没有固定奖励或惩罚。新增参数共 `4 × hidden_size + 1` 个，不堆叠历史棋盘。有限历史帧本身也不能覆盖任意长度的重复，规则仍由裁决器执行。

训练、搜索和 UCI 共享特征编码；黑方视角、左右镜像和回放存储同步转换候选着标记。旧样本新增通道为零且标记历史未知。没有增加预算剩余步数输入，也没有改变终局标签或截断价值屏蔽机制。
