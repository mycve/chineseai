# 吃子共享关系扩展

## 实现

保留原策略结构，在原战术张量末尾增加 1568 个参数：移动棋子 7 类 × 被吃棋子 7 类 × 五位战术状态 32 类。状态沿用起点受攻、终点受攻、起点保护、终点保护和将军标记。只对吃子走法增加一个共享残差，不展开走法或棋盘坐标维度。新增参数 6.125 KiB。

CPU 复用当前已计算的被吃子编号、攻击图和将军标记；只对吃子走法增加一次小表读取和一次浮点相加。没有增加棋盘遍历、试走、吃回搜索或神经网络层。训练复用融合战术算子，将索引数从二项增为三项；非吃子和填充走法指向零哨兵，CUDA 前向与反向同步更新。

推理缓存同时压缩不可达棋子槽位，约减少 4.625 MiB/网络。训练原有大表布局保持不变。

## 训练方式

从头训练，新建模型的吃子关系权重初始化为零。当前模型格式为 34，不提供旧模型或旧优化器状态的转换工具。

## 验证范围

索引覆盖、同类关系在不同走法间共享、非吃子哨兵、CPU 与训练前向一致性、融合算子梯度、新参数梯度和保存加载是工程验证。已有消融只表明当前模型依赖原共享战术项，不能证明新增关系涨棋力。

原局面的攻击图不等于落子后的合法回吃判断。该扩展只影响 policy，不直接修复 value 高估。实际 NPS 与重新训练后的棋力尚须分别验证，不能将参数少当作已经验证提速。
